# 65W GaN 充电器 DVT 温升超差 —— 出货决策建议

**提交对象**：项目经理 / DVT 评审会
**提交人**：研发（热设计）
**议题**：45℃ 环境满载 30min，外壳最高点 78℃，规格线 75℃，是否可按现有方案出货
**日期**：DVT 评审会前

---

## 一、结论

**现在不能签字放行，但也不需要立刻开模。**

我的建议是走"本周验证、周四定案"的两段式：在评审前用不改模的手段（导热垫 + 固件高温降额）把 78℃ 压到 73℃ 以下，拿到 2K 设计余量；如果验证通过，按原方案出货，模具不动、认证不动，BOM 只增加 1 元左右；如果验证不通过，再开模，并且把开模范围收窄到局部改模而不是整套新模。

**明确反对的路径：带 78℃ 出第一批货，下一版再改。** 理由在第四节——"下一版"不是 3 周，是 13～17 周，这批货在整个生命周期内都超规格，不存在补救窗口。

---

## 二、三个会翻转结论的前提

这三件事现在没有确认，任何一条被推翻，下面的推荐都要重写。我把它们放在最前面，是因为周四会上大概率会有人问。

**1. 78℃ 那个点是塑料还是金属？**
如果是塑料外壳外表面，78℃ 属于"烫但可握持"，是体验和余量问题，可以谈。
如果是 USB-C 金属口、外露螺丝、金属装饰件，那 78℃ 直接触碰就是安规可触及表面的问题，结论立刻变成**不可出货**，没有中间地带，后面的方案全部作废。这一条请硬件在周三前用红外 + 热电偶双确认，并拍照片存档。

**2. 75℃ 这条线是谁定的？**
- 如果是 IEC 62368-1 的可触及表面限值 → 硬红线，超了就是不合格品，只能改设计，不存在让步接收。
- 如果是客户规格书条款 → 可以谈，但必须走客户书面让步（Concession），口头的、会议纪要里的都不算。
- 如果是我们自己的内控手感标准 → 走内部规格变更流程即可，成本最低。

请质量在周三前把 75℃ 的出处（哪份文件、第几条）发出来。**这一条是整件事的分水岭**：如果是第三种，事情的性质就从"质量事故"变成"规格修订"，一个流程就能解决，不需要 12 万。

**3. 78℃ 是一台的数，还是一批的数？**
DVT 阶段至少应有 5 台数据。如果 78 是十台里的最差值、其余在 73～75，那是个体差异叠加测量噪声，批次风险低；如果十台全在 77～79，那是设计本身没有余量，批次风险高。请测试在周二前补测 5 台，报**最大值、最小值、均值、极差**四个数，不要只报一个最大值。

顺带说一句测量本身：同一台机器、同一位置、重新贴片重测三次，离散度通常有 ±1～1.5K。现在这 3K 超差里，有多少是真实余量不足、有多少是贴片差异，没人分过。这个必须分开，否则后面所有讨论都建立在一个不牢的地基上。

## 三、数据本身说明了什么

先把绝对温度换算成温升，因为温升才是设计的真实指标：

| 指标 | 数值 |
|---|---|
| 45℃ 环境外壳最高点 | 78℃ |
| 温升（相对环境） | **33K** |
| 规格线 75℃ 对应温升 | 30K |
| 超差 | 3K，占温升的 9.1% |
| 按温升线性推算 25℃ 环境 | 约 58℃ |
| 按温升线性推算 40℃ 环境 | 约 73℃ |

三个可以直接用的判断：

**第一，这台机器在常温下是正常的。** 25℃ 环境推算 58℃，离 75℃ 还有 17K 余量。问题只在高温端，不是全局性的设计失败。这意味着修复不需要推倒重来。

**第二，40℃ 环境下推算 73℃，刚好在线上。** 如果产品标称工作温度上限是 40℃（多数消费类充电器的实际标注），那么 45℃ 本身就是超出额定工况 5K 的余量验证，78℃ 的性质是"余量不足"而不是"不合格"。请产品在周三前确认规格书写的工作温度范围——**这一条如果成立，是最省钱的解法：把 45℃ 满载这个条件从"必须满足"降级为"降额后满足"，一句话的事。**

**第三，3K 不是一个大数字，但它吃掉的是全部余量。** 设计余量的意义在于覆盖批次差异、元件公差、老化衰减、灰尘堵塞。现在余量是负的 3K，意味着任何一台稍微差一点的机器、任何一个效率低 0.5% 的批次，都会更差。这不是"超一点点没关系"，是"没有容错空间"。

## 四、为什么"先出货、下版再改"是最差选项

PM 说改模交期加 3 周。这 3 周是**模具加工周期**，不是版本周期。把后面的环节排一遍：

| 环节 | 周期 | 说明 |
|---|---|---|
| 改模加工 | 3 周 | PM 说的 3 周 |
| 试模 + 尺寸/装配验证 | 1～2 周 | 新模具首件必检 |
| 安规重测 | 3～6 周 | 结构变更后全项或部分项重测，实验室排期不可控 |
| DVT 复测（温升 + 可靠性） | 2 周 | 需新结构样机 |
| PVT + 量产爬坡 | 3～4 周 | |
| **合计（部分可并行）** | **13～17 周** | |

也就是说"下个版本"是明年一季度的事，不是下个月。这批货从上市到退市，全程超规格，**没有任何一个时间点是被"下一版"救回来的**。所谓"下版再改"，实际含义是"这一批永久性超规格，且我们留下了书面记录"。

再算一笔钱：12 万摊到 3 万台是 **4 元/台**。一次批量返工 3000 台（物流 + 人工 + 料，按 40 元/台）就是 12 万，正好打平；一次客户抽检不合格导致的退货或索赔，量级在几十万；如果触发认证抽查不合格，是整批扣货加整改。**所以 12 万根本不是决策变量，别在会上纠结这个数。** 真正的变量是 6～8 周的交期，以及"要不要把一个已知超规格的产品放出去"这个立场问题。

## 五、五个选项的对比

| 选项 | 一次性成本 | BOM 增量 | 交期影响 | 认证影响 | 技术风险 | 评价 |
|---|---|---|---|---|---|---|
| **A. 原样出货** | 0 | 0 | 0 | 无 | 批次 100% 超规格，高温环境客诉风险高 | **反对**，除非拿到客户书面让步且限定出货区域 |
| **B. 不改模补救**（导热垫 + 点胶 + 固件降额） | 验证费约 0.5 万 | +0.5～1.5 元/台 | 1～2 周 | 大概率无需重测（非安规结构件） | 降温幅度需实测，预估 5～9K | **推荐首选** |
| **C. 局部改模**（加散热筋/镶件/导热柱，不开通风孔） | 3～6 万 | +0.3 元/台 | 4～5 周（含试模） | 视是否触及爬电/开孔而定，可能部分重测 | 低 | B 不达标时的次选 |
| **D. 整套改模 + 开通风孔** | 12 万 | +0.3 元/台 | 6～8 周（含重测） | 需重测 | 低（降温最彻底） | 效果最好但周期最长 |
| **E. 修订规格 / 高温降额出货** | 0 | +0.1 元/台（NTC） | 1 周 | 需评估输出能力变化 | 需客户或市场同意 | **成本最低**，取决于第二节第 2 条的答案 |

注意 C 和 D 的区别：**真正必须开模的只有开通风孔这一条路**。如果只是为了加散热筋、加导热柱、给导热垫留个凹槽，用镶件改模通常在 3～6 万，而且不改变外壳开孔，安规重测范围可以谈。现在直接跳到"12 万整套改模"，是因为没人验证过 B 能不能解决问题。

## 六、不改模的五种手段（选项 B 的具体做法）

按性价比排序，都可以在本周内用现有样机验证：

**1. 固件高温降额（最可靠，优先做）**
加一颗 NTC 检测环境/壳内温度，超过 42℃ 时把输出从 65W 折到 50W。损耗大致按电流平方下降，温升从 33K 降到 21K 左右，外壳落在 **66～68℃**，余量 7～9K。
成本：NTC + 分压电阻约 0.1 元；固件改动 2 天。
认证影响：不涉及结构，但输出能力曲线变了，需要跟安规确认是否影响铭牌和温升测试的判定。
代价：45℃ 下不能满功率。这需要在规格书上写清楚，或者由市场确认可接受。**这是唯一一个有确定数学预期的手段，其他都是经验值。**

**2. 导热垫 / 导热凝胶填充**
在变压器、GaN 器件、同步整流 MOS 与外壳之间填 2～3mm 导热垫（3～5 W/m·K）。预期降 **1～3K**，取决于间隙和接触面积。
成本：0.3～0.8 元。
认证影响：无。导热垫不是安规件，不改变爬电距离和阻燃等级。
风险：如果间隙小于 1.5mm 或者结构上有装配公差，垫子压不实，效果会打折。要先量间隙。

**3. 石墨 / 铜箔均温片**
把热点摊开。峰值能降 **2～4K**，但平均壳温会升 1～2K。
成本：0.5～1.5 元。
认证影响：无（注意铜箔要可靠固定，不能松脱）。
适用条件：只有当规格考核的是**最高点**时才划算。如果客户考核的是外壳平均温升或者多点取样，这招是负收益，要先确认考核方式。

**4. 功率器件点导热胶**
变压器绕组和 MOS 背面点高导热硅胶，改善到 PCB 铜层的传热。预期 **1～2K**，成本 0.2 元。可以和 2 叠加。

**5. PCB 加铜厚（2oz）**
预期 **2～3K**，但需要 PCB 改版，周期 2～3 周，且成本涨 8～12%。**本周做不了，只能作为 B 失败后的补充，不算在本周验证范围内。**

**叠加上限的现实预期**：2 + 3 + 4 三项叠加，乐观 5～6K，保守 3～4K。加上固件降额，总量足够。但如果只做 2、3、4 而不做固件降额，**大概率只能到 74～75℃，仍然贴着线，不解决问题**。所以固件降额是主力，其余是辅助。

## 八、周四会上我给什么

**如果三项前提全部澄清、且补测数据显示批次一致性好（极差 ≤2K）：**

> 建议走选项 B。本周内完成导热垫 + 固件降额的样机验证，目标 ≤73℃。验证通过则按原方案出货，模具不动，BOM 增加约 1 元，交期不加。验证不通过则转选项 C 局部改模，同时启动客户沟通。

**如果 78℃ 是金属可触及件：**

> 不可出货。无中间方案，直接开模，同时评估是否需要召回已发出的工程样机。请安规同步确认可触及表面限值条款。

**如果 75℃ 是内控标准：**

> 走规格变更流程，同步做选项 B 的降额，把实际表现和标称对齐。不需要 12 万。

**如果会上必须当场给一个字：**

> **不签。** 我给的是"条件性不签"——条件在第二节，三个问题周三前回答完，周四就能签。

## 九、如果最终被迫放行，必须同时满足六条

我不建议走这条路，但如果商务上确实没有退路，放行必须同时具备以下六条，缺一条我都不签字：

1. **客户书面让步**，不是邮件确认、不是会议纪要，是盖章的 Concession，写明超差项、超差值、有效期、适用批次号。
2. **限定出货范围**：只发常温市场，不发中东、东南亚、车载、户外渠道；按订单号锁定，销售系统里打标。
3. **铭牌和说明书加降额声明**：45℃ 以上环境输出降至 50W，或在包装上标注工作温度上限 40℃。
4. **加严出货抽检**：每批抽 5 台做 45℃/30min 温升，超 76℃ 整批扣货。这一条是给自己留的止损阀。
5. **下一版强制切换**：把温升整改写进下一版的 DVT 准入条件，挂到版本里程碑上，有责任人和日期，不能只是"下次改"。
6. **留一份技术备忘录归档**：记录当时的判断依据、风险接受人、决策链。这不是形式主义——真出了事，这份文件决定了责任落在谁头上。

## 十、一句话总结

3K 的超差、12 万的模具费、3 周的交期，三个数字看起来都不大，但它们组合起来指向一个不能含糊的判断：**这个产品在高温端已经没有设计余量了，而"下一版"救不了这一批。** 所以不要在原样出货和整套改模之间二选一，先用一周时间证明不改模能不能解决——大概率能，代价是 1 元 BOM 和一份降额说明。
