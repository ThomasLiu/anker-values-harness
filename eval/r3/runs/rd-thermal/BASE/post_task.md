# 复盘：这次温升超差决策

## 一、做对了什么

**把"二选一"还原成了五个选项。** PM 递过来的问题是"按现有方案出货，还是改模"，这个问法本身就把决策空间压扁了。我做的第一件事是列中间路径：导热垫、均温片、点胶、固件降额、局部改模。这五条路里，只有开通风孔是真的必须开模，其余都不动结构件。把这个列出来之后，"12 万 + 3 周"从一个既定前提变成了一个待验证的选项，会议的性质就变了。

**把 12 万从决策变量里拿掉了。** 12 万摊到 3 万台是 4 元/台，一次 3000 台的批量返工就打平。会上一旦开始讨论"12 万值不值"，讨论就已经跑偏了——真正的成本是 6～8 周的交期和认证重测的不确定性。把这句话说出来，比任何技术分析都更能让会议回到正轨。

**修正了交期账。** PM 说的 3 周是模具周期。把试模、安规重测、DVT 复测、PVT 摊开算，是 13～17 周。这个修正直接推翻了"下版再改"这个选项的可行性——因为"下版"不是下个月，是明年一季度，这批货没有任何补救窗口。这是整份文档里最有杀伤力的一段，也是最容易被忽略的一段。

**用温升代替绝对温度。** 78℃ 对 75℃ 是 3K，看起来是"差一点"。换成温升 33K 对 30K，超 9%，再换算到 25℃ 环境是 58℃、40℃ 环境是 73℃——三个数字一摆，"这台机器常温正常、只在高温端没余量"这个判断就立住了。这比争论 78 到底烫不烫有效得多。

**守住了签字边界。** 研发能给技术风险判定，不能给放行许可。文档里我把"条件性不签"写得很清楚：三个问题周三前回答完，周四就能签。这样既没把决策踢回给 PM，也没替质量背责任。

## 二、做错了什么 / 没做到的

**没有在拿到任务的第一时间要求补测数据。** 我是在写文档的过程中才意识到 N=1 这个问题的。正确顺序应该是先发一条消息给测试要 5 台数据，再开始写分析——数据回来的时候文档也差不多写完了，能省一天。现在是文档先出、数据后补，周四之前的时间被压得很紧。

**降温幅度的预估都是经验值，没有实测支撑。** 导热垫 1～3K、均温片 2～4K、点胶 1～2K，这些数字来自过往项目的印象，不是这个产品的实测。我在文档里标注了"预估"，但会上如果有人追问依据，我只能说"经验"。唯一的例外是固件降额，那个有损耗平方律的推算，相对可靠。**这是这份交付物最薄弱的环节**——如果周四之前能在一台样机上实测导热垫的效果，整份文档的可信度会上一个台阶。

**假设写得太靠后了。** 四条默认前提我放在了 pre_task 里，但在 pre_deliver 里只体现在第二节的"三个翻转条件"中，而且没有明确说"如果 78℃ 是金属，整份文档作废"。会上很可能有人跳过第二节直接看结论，然后拿着"建议走选项 B"去执行。应该在第一段就加一句黑体警告。

**没有算良率。** 如果补测显示批次极差有 4～5K，那 78 可能只是均值加 2σ 的结果，实际批次的分布会更宽，出货抽检的判定线（我写了 76℃）就需要重新定。这个我完全没考虑，是遗漏。

## 三、这件事暴露的组织问题

**规格线没有归属。** 75℃ 是谁定的、依据是什么，问到第三个人还没人说得清。一个没有出处的规格线，在超差的时候就没法判断是"红线"还是"目标"。这不是这次的问题，是流程的问题——每条关键规格都应该有 owner、有出处、有变更路径。建议这次之后把热规格清单过一遍。

**"改模"被当成了默认答案。** 从 PM 到结构，第一反应都是改模。没有人问过"不改模能不能解决"。这说明团队里热设计和结构是割裂的：结构只负责"模具怎么改"，热设计只负责"测出来多少度"，中间"怎么用最小代价降温"这一段没人负责。这次是我临时补上的，下次应该固化成流程——温升超差的第一轮响应必须是"不改模方案筛查"，而不是直接进改模评估。

**认证的影响范围是拍脑袋的。** "动了安规相关结构要重测"这句话是对的，但太粗。导热垫、点胶、固件降额算不算"安规相关结构"？大概率不算。但没人去查具体条款，就直接按"要重测"来估周期，结果把一个本来 2 周能做完的事估成了 8 周。**认证影响必须问到条款级，不能停在"要重测"这种模糊判断上。**

**样机数量在 DVT 阶段就不该是问题。** DVT 做 5 台是最低要求，现在手上只有一台的数据，说明要么没测够，要么测了没记录。这是测试管理的问题，不是这次决策的问题，但它让这次决策变得格外难做。

## 四、下次怎么做

1. **拿到问题的第一小时**：先判断这是"数据不足"还是"判断分歧"。数据不足就先去要数据，别急着写分析。
2. **任何超差问题，先做三件事**：确认规格出处、确认测点材质、确认样机分布。这三件事不做完，后面的分析都是空中楼阁。
3. **永远先列不改设计的方案**，再列改设计的方案。改模、改板、改料是最后手段，不是第一手段。
4. **成本换算成单台**。12 万 / 3 万台 = 4 元，这个换算能瞬间改变会议的讨论方向。
5. **周期要拆到环节**。任何"加 N 周"的说法，都要拆成加工、验证、重测、爬坡四段分别估，因为后三段经常比第一段长。
6. **交付物第一段就要有翻转条件**，不能藏在第二节。

## 五、还没验证的东西

- 导热垫的实际降温幅度（本周内可测，未测）
- 78℃ 测点材质（待硬件确认）
- 75℃ 的规格出处（待质量确认）
- 批次分布（待补测）
- 安规重测的具体范围（待安规确认）
- 45℃ 满载是否为客户承诺（待产品确认）

这六项里，前四项决定结论方向，后两项决定执行成本。周四之前如果只能拿到两项，优先要前两项——**材质和规格出处，这两个比数据本身更能决定这件事的性质。**
