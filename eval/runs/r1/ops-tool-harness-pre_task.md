# 任务拆解卡：5 人团队「轻量 ATS」选型

任务原文：我们现在的候选人管理是靠 Excel + 微信，越来越乱。想上个轻量的 ATS。预算一年 2 万以内，团队 5 个人。给我个方案。

---

## 真实目标

- **表面需求**：采购一个「轻量 ATS」软件，替代现在的 Excel + 微信。
- **我判断的真实目标**：让 5 个人对同一批候选人拥有唯一事实源，并且录入成本低到大家真的会用。核心痛点是「状态不可见 + 沟通不留痕 + 无人负责跟进」，这是协作与留痕问题，不是功能覆盖问题。
- **依据**：
  1. 用户描述的「乱」是三个具体现象——候选人散在多个 Excel、沟通记录在个人微信、没人知道某个候选人卡在哪一步。这三条都不是「缺功能」造成的，是「缺唯一写入点」造成的。
  2. 5 人团队不存在跨部门审批、编制管控、雇主品牌等 ATS 高阶需求，功能矩阵对本场景几乎无增量价值。
  3. 预算 2 万/年对 5 人团队不算少，但也不是能买一体化 HR SaaS 的量级，选错方向的成本高于选贵一点的成本。
- **由此推出的第一性判据（排序不可颠倒）**：录入成本 < 状态可见性 < 预算上限。理由：任何需要 HR 每天手工搬数据的系统，在 5 人团队里 2 周内必然被弃用，回退到 Excel；功能再全也无意义。
- **一个必须验证的反向可能**：本场景可能不需要买 ATS，而需要先定 1 页招聘 SOP + 一张结构化 Excel 模板 + 共享文档。如果验证后发现「乱」主要来自流程缺失而非工具缺失，方案应改为「流程先行、工具后置」，把 2 万留给招聘渠道。这一点我在交付稿里会作为备选方案之一正面处理，不会默认跳过。

## 问题拆解（拆到不能再拆）

| 子问题 | 现状表现 | 可判定症状 | 方案里对应模块 |
| --- | --- | --- | --- |
| P1 状态不可见 | 候选人阶段只存在于某个人脑子里或某个 Excel 里 | 问「张三到哪一步了」需要 5 分钟以上才能答出 | 候选人主档 + 阶段看板 |
| P2 沟通不留痕 | 微信一对一聊完就散，换人接手等于从零开始 | 换一个面试官接手，需要重新问候选人已答过的问题 | 沟通记录挂在候选人档案下 |
| P3 渠道分散 | BOSS / 邮箱 / 内推 / 微信 各来一份简历，重复投递识别不了 | 同一候选人被 2 个人分别联系 | 简历统一入库 + 去重 |
| P4 无跟进机制 | 没有提醒，候选人放凉了才发现 | 超过 7 天未跟进的候选人数量 > 0 且无人知晓 | 待办 / 超时提醒 |
| P5 数据不可用 | 想知道「哪个渠道来的候选人转化高」答不出来 | 无法按渠道统计到面率 | 渠道来源字段 + 简单报表 |
| P6 迁移成本 | 现有 Excel 里有历史候选人 | 历史数据丢失或需要手工重录 | 批量导入 |

P6 单独列出来是因为它最容易被方案忽略，也最容易在实施阶段变成隐性成本。

## 关键假设

- 假设：年招聘量 15–30 人、同时在招岗位 5–8 个、月新增简历 200–400 份 → 验证：拉近 12 个月 Excel 的候选人行数，与微信/BOSS 里新增候选人数量对齐，取实际值；若月简历 < 100 份，则 ATS 的必要性大幅下降。
- 假设：团队日常办公 IM 是飞书或企业微信之一，而不是纯个人微信 → 验证：直接问 5 个人平时用哪个 IM 谈工作；这决定 ATS 能否靠 IM 打通降低录入成本，也决定是否需要额外做 IM 迁移。
- 假设：2 万/年是「软件订阅」预算，不含 BOSS 直聘 / 猎聘等渠道年费 → 验证：向决策人确认预算科目边界；若 2 万含渠道费，方案必须改为「渠道优先 + 免费/低代码 ATS」。
- 假设：团队无专职 IT，不能承担自建服务器的运维 → 验证：确认是否有可支持的人和机器；若无，直接排除开源自建路线（Odoo 等），不留作候选。
- 假设：供应商公开报价与最终成交价差异可达 ±30%，且普遍按「HR 席位 × 年」计价 → 验证：向 3 家供应商索取「5 席位 / 1 年」的正式书面报价，以最低书面价作为预算基线，不接受口头报价。
- 假设：候选人愿意被记录在系统里，不存在合规障碍（个人信息保护） → 验证：确认是否需要候选人授权话术；若需要，方案里必须包含一条授权告知模板，否则存在合规风险。

## 验收标准

- **单一事实源**：任一候选人的当前阶段，在 1 个页面内可查；5 人团队的候选人覆盖率 = 100%，不允许存在「只活在微信聊天记录里」的候选人。
- **录入成本**：从收到简历到建档完成 ≤ 2 分钟/份；且 ≥ 80% 的简历通过邮箱或渠道自动入库，不需要手工复制粘贴。
- **沟通可追溯**：抽样 20 条关键沟通，≥ 18 条能在候选人档案下找到对应记录（摘要即可，不要求全文）。
- **预算硬约束**：首年总支出（订阅 + 实施 + 数据迁移）≤ 20000 元；续费年 ≤ 20000 元；不得存在按简历量或沟通量计费的不可控项。
- **上线周期**：从签约到 5 人全部日常使用 ≤ 10 个工作日；判据为连续 5 个工作日无人回退到 Excel 记录新候选人。
- **数据可迁出**：合同期内可随时全量导出候选人 + 沟通记录为 CSV/Excel，导出完整率 = 100%，做不到即判定为不通过。
- **弃用成本**：方案必须写明退出路径（导出方式 + 数据保留期），退出成本判据为「不需要供应商配合也能拿回全部数据」。
